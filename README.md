# STKA Pharma Craft

Build a production-quality, premium, minimalistic pharmaceutical corporate website for:

COMPANY NAME:

STKA Pvt Ltd

WEBSITE TYPE:

Pharmaceutical Manufacturing / Corporate Website

IMPORTANT:

This is NOT an online pharmacy and NOT an e-commerce website.

The website should present STKA Pvt Ltd as a trustworthy, quality-focused, modern pharmaceutical manufacturing company.

==================================================

1. OVERALL DESIGN DIRECTION

==================================================

Create a sophisticated, minimalistic, premium corporate design.

The website should communicate:

- Trust

- Pharmaceutical quality

- Scientific excellence

- Manufacturing capability

- Regulatory compliance

- Reliability

- Innovation

- Professionalism

- Long-term partnerships

The visual style should feel like a serious pharmaceutical manufacturer, NOT like:

- A hospital

- A medical clinic

- An online pharmacy

- A generic healthcare template

- A flashy SaaS startup

Design principles:

- Lots of whitespace

- Strong typography hierarchy

- Clean layouts

- Elegant spacing

- Minimal visual clutter

- Subtle borders

- Very light shadows

- Restrained use of rounded corners

- High-quality pharmaceutical imagery

- Subtle animations

- Excellent mobile responsiveness

Avoid:

- Excessive gradients

- Glassmorphism

- Neon colors

- Excessive animations

- Huge rounded cards

- Excessive floating elements

- Cartoon illustrations

- Generic medical icons everywhere

- Fake statistics

- Fake certifications

- Fake reviews

- Fake company history

- Unsupported medical claims

==================================================

22. RESPONSIVE DESIGN

==================================================

The website must be fully responsive.

Optimize for:

Desktop

Laptop

Tablet

Mobile

Mobile design is extremely important.

Do not simply shrink the desktop layout.

Create intentional mobile layouts.

Make sure:

- Navigation works perfectly

- Images scale correctly

- Typography remains readable

- Buttons are touch-friendly

- Product cards work well

- Forms are easy to use

- No horizontal scrolling

- Tables/content don't overflow

26. PERFORMANCE

==================================================

Prioritize performance.

Use:

- Optimized images

- Lazy loading

- Responsive images

- Minimal JavaScript

- Efficient components

- Avoid unnecessary dependencies

- Avoid huge background videos

- Avoid oversized image assets

The website should feel fast even on mobile networks.

==================================================

27. BACKEND-READY ARCHITECTURE

==================================================

The frontend will eventually connect to a Spring Boot REST API.

Design the frontend architecture so static mock data can easily be replaced with API calls.

Expected backend resources:

/api/v1/company-information

/api/v1/categories

/api/v1/products

/api/v1/products/{id}

/api/v1/products/slug/{slug}

/api/v1/certifications

/api/v1/certifications/{id}

/api/v1/enquiries

Do not tightly couple UI components to mock data.

Create reusable TypeScript types/interfaces.

Separate:

components

pages

layouts

types

services/api

hooks

utils

where appropriate.

==================================================
